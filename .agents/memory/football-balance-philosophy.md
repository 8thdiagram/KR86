---
name: Football balance philosophy
description: The user's intended relationship between play selection, player ability and actual football execution.
---

Good play call + good players + good execution should improve the probability of success. A good defensive counter + good defenders + good execution should improve the probability of stopping the play. Neither side should receive guaranteed outcomes solely from play selection.

**Why:** The user wants meaningful rock-paper-scissors anticipation before the snap and entertaining arcade execution during the play, not predetermined outcomes or rigid NFL statistical reproduction.

**How to apply:** Judge proposed football balance changes using actual gameplay outcomes, personnel differences and execution together. Inside runs should sometimes produce a usable blocking lane, several yards or a secondary breakthrough, while a correctly anticipated run defense should reduce those opportunities rather than automatically stop every run.
